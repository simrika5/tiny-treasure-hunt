💎 Tiny Treasure Hunt

A fun, beginner-friendly Python terminal game where you search a grid to find hidden treasure!

🎮 How to Play
Search the 5×5 grid by entering row and column numbers.
Follow the hot and cold hints to locate the treasure.
Find it before you run out of attempts.
Earn points and try to beat your high score!
🚀 Getting Started

Requirements: Python 3.8+

bash
git clone https://github.com/YOUR_USERNAME/tiny-treasure-hunt.git
cd tiny-treasure-hunt
python main.py

✨ Features
Randomly hidden treasure
Hot and cold hints
Limited attempts
Score tracking
Replay support
No external dependencies
